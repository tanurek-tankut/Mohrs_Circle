# Mohrs_Circle
Mohr's Circle Analysis
================================

A simple and single-file Python application that interactively visualizes **Mohr’s Circle**, stress transformations, and free-body rotation using basic input values. 
This tool provides a quick visualization of principal stresses, maximum shear stress, and stress transformation for a given state of stress.
